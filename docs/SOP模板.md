## 7. 操作前检查

逐项确认并记录，不允许以“默认正常”代替检查。

- [ ] 人员资质和培训在预计执行结束前有效
- [ ] 设备校准/维护有效，序列号与系统台账一致
- [ ] 工位空闲、已清洗、联锁正常、适配器在线
- [ ] 物料批号已放行、未过期、可用量充足
- [ ] 样本身份、数量、容器和孔位一致
- [ ] 方法、SOP、计划均为当前批准版本
- [ ] 危废容量、PPE 和应急物资满足要求

## 15. 发布前核对

- [ ] 文件编号、版本、生效期、适用能力和样本类型完整
- [ ] 所有参数均有单位、范围和异常动作
- [ ] 人员资质、设备校准、物料放行要求可由系统校验
- [ ] 自动设备的超时、去重、查询、保持、终止能力已如实声明
- [ ] 记录字段能支持样本—批次—人员—设备—物料—方法/SOP 全链追溯
- [ ] 风险控制、偏差处理、清洗和危废步骤已由责任人确认
- [ ] 复核人与批准人不是起草人本人（如质量体系要求职责分离）
